# Holodeck development

This is an early local world-authoring prototype published for public GitHub
development. It has persistent worlds, an editable bible and mood board,
validated Kiln asset hot loading, a native local Codex connection, world history,
and static export. The cove is the starting workspace; Tidemark Island,
courtyard and kinetic examples use shared data-driven contracts. Historical
mocked-agent studies remain separate from the live workflow. Read README.md,
docs/architecture.md and docs/distribution.md. Keep private analysis, captures
and lineage outside this repository. Public examples must be independent fixtures.
The npm package stays private; npm publication is outside the current scope.
Keep Kiln on the local Node side; do not import its root SDK into browser bundles.
Keep real measurements distinct from mock UI, generated concepts, and targets.
Do not commit, push, create a remote, publish, or deploy without user authorization.
Retain exact dependency pins and evidence of WebGPU and forced WebGL2 results.
Never read or copy agent credentials. Asset authoring belongs in a separate
Kiln workspace, not the engine checkout or this toolchain checkout.

Code and procedural asset programs are MIT. Designated bundled assets and example
world data are CC0; preserve third-party notices and the scope in LICENSING.md.
User-created world content does not automatically inherit the bundled asset dedication.
