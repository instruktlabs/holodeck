# Workflow knowledge ledger

This ledger turns demonstrated authoring and integration failures into reusable
product knowledge. It follows the agreed [integration boundary](integration-boundary.md).
The current Kiln dependency is pinned to 1.4.0. A fixed regression is not a claim
that all art, routes, devices or performance targets are qualified.

Work proceeds through the approved sequence: finish the pinned Holodeck adapter,
guidance and bounded shadow changes, establish a matched reference-machine
baseline, then assess any reproduced Kiln core issue. Product naming is approved;
publication and a dependency upgrade are separate decisions.

**Fixed** means the relevant behavior has a regression or bounded runtime check.
**Supported with limits** identifies an intentional capability boundary.
**Open** identifies work that is not implemented or not yet established by the
available evidence. Test names below refer to repository suites, not to tests
included in an installed world or a performance guarantee.

Use the ledger to choose a bounded next task, not to claim every open item must be
built. Keep authoring guidance advisory where correctness is not enforceable.
Update a row when its reproduction, implementation or evidence changes. Preserve
general knowledge in maintained package skills; existing workspace copies require
an explicit, customization-preserving update path.
