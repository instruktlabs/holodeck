# Optional material starter shortlist

Catalog research checked 2026-10-26. These are candidates for qualification, not
installed or runtime-approved packs. Start with 1K/2K and measure cost before
offering higher-resolution downloads. Preserve provider and license provenance.

| Candidate | Intended first test | Curation concern |
| --- | --- | --- |
| [Fine Grained Wood](https://polyhaven.com/a/fine_grained_wood) | Continuous grain on individual case slats; first priority | Verify grain direction, seam continuity and end-grain treatment |
| [Weathered Brown Planks](https://polyhaven.com/a/weathered_brown_planks) | Broad exterior plank surfaces | Baked joints must agree with modeled boards |
| [White Plaster 02](https://polyhaven.com/a/white_plaster_02) | Neutral interior walls and lighting comparison | Micro-normal and brightness at grazing angles |
| [Concrete Floor 02](https://polyhaven.com/a/concrete_floor_02) | Floor/ground repeat and roughness test | Repetition, scale and retained stain detail |
| [Corrugated Iron](https://polyhaven.com/a/corrugated_iron) | Weathered metallic roofing | Large ridges require silhouette geometry at close range |
| [Red Brick 03](https://polyhaven.com/a/red_brick_03) | Wall scale, mortar normal and AO test | Brick dimensions and corner continuity |
| [Stone Brick Wall 001](https://polyhaven.com/a/stone_brick_wall_001) | Rough masonry | Deep mortar cannot be represented by normals at every distance |

These pages expose color, OpenGL normals, roughness and packed AO/roughness/metal
downloads. Confirm actual file bytes, dimensions, physical coverage and channel
packing at ingestion. Poly Haven publishes assets under [CC0](https://polyhaven.com/license),
including permission to redistribute them; that makes qualified derivatives viable
for a bundled starter pack. Link to the original free source and credit the creators.
Its [live API terms](https://github.com/Poly-Haven/Public-API/blob/master/ToS.md)
are separate from the asset license. No live API integration has been installed here.

The tested [Megascans veneer](https://www.fab.com/listings/b514d475-4115-4012-88b0-f85c61fedca5)
stays a user-download catalog entry under the [Fab Standard License](https://www.fab.com/eula).
It is technically integrated but conditionally suitable: the panel grooves conflict
with case slat geometry. See [the trial](megascans-wood-results.md).

Promotion gate: known license and original hashes; reproducible map normalization;
physical UV scale; tiling/normal/roughness inspection; native and browser capture;
update preserving interaction/overrides; decoded-pixel integrity; mip/cost review;
explicit suitability notes. Passing ingestion alone never promotes a texture.
