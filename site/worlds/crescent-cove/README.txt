Holodeck static scene

Upload the entire directory to any static HTTP(S) host. Keep relative paths intact; subdirectory deployment is supported. No Node server, account, agent, or API endpoint is required. Open index.html through the host, not file://. HTTPS enables WebGPU where available; WebGL2 is the fallback. Add ?backend=webgl to force it.

Enter world: WASD move, Shift run, Space jump and V first/third person when the scene has an inhabitant. G toggles free camera; Q/E descend/ascend there. E interacts while walking. Escape stops mouse capture and returns to the overlook. Right-drag works without mouse capture. The toolbar controls cove visibility, activity pause and return to arrival.

This artifact contains an accepted scene revision and exact pinned GLB bytes. Authoring prose, board references, agent history, credentials and source workspace files are excluded. Asset metadata embedded in the original GLBs is retained unchanged; publication rights remain the asset owner's responsibility. The manifest records SHA-256 hashes of every delivered file except itself.
